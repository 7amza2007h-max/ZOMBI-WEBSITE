ZOMBI WEBSITE V9.2 — RENDER — FULL REPLACEMENT
===============================================

التركيب على GitHub / Render:
1) فك ZIP.
2) ارفع كل الملفات الموجودة داخل ZIP إلى ROOT مستودع الموقع في GitHub.
3) اعمل Replace للملفات القديمة ثم Commit / Push.
4) على Render احتفظ بمتغيرات البيئة الحالية وتأكد من:
   PUBLIC_BASE_URL=https://YOUR-RENDER-DOMAIN
   DISCORD_CALLBACK_URL=https://YOUR-RENDER-DOMAIN/auth/discord/callback
   DISCORD_CLIENT_ID=<Application ID>
   DISCORD_CLIENT_SECRET=<Application Secret>
   BOT_TOKEN=<Bot Token>
   OWNER_IDS=<Discord User ID للمالك>
   SESSION_SECRET=<قيمة عشوائية قوية>
   DATABASE_URL=<نفس Neon المستخدم في Lunafy>
   DATABASE_SSL=true
   HOME_GUILD_ID=<ID سيرفر ZOMBI الأساسي>
5) Build command: npm install
6) Start command: npm start
7) بعد Deploy افتح /health وتأكد أن ok=true.

الجديد في Dashboard V9.2:
- تصميم احترافي Obsidian/Violet مع Sidebar وأقسام أوضح.
- قسم بنك ونهب كامل: مدة السجن، سعر الكفالة، سعر حماية الكاش، مدة الحماية، كولداون الحماية، وكولداون كل لعبة نهب.
- تشغيل/إيقاف كل لعبة نهب على مستوى السيرفر.
- اختيار رتبة أو عدة رتب تستطيع بدء الألعاب العادية.
- Owner Panel: اختيار ألعاب النهب المتاحة لـ Free وPremium.
- Owner Panel: التحكم برسالة ترويج Premium، نسبة ظهورها، والكولداون.
- Free الافتراضي: لعبتا نهب أساسيتان. Premium الافتراضي: جميع ألعاب النهب السبعة. ويمكن للOwner تغيير ذلك.

مهم:
Render وLunafy يجب أن يستخدموا نفس DATABASE_URL حتى تنعكس تغييرات Dashboard على البوت مباشرة.
