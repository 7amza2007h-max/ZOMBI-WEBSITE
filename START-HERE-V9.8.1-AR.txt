ZOMBI V9.8.1 — تحديث اللوج والتحذيرات
هذا تحديث فوق V9.8.0. الملفات المرفقة كود فقط؛ لا تحذف ملفات البيانات أو .env.

1) البوت: فك ملف BOT في مجلد البوت على Lunafy، مع استبدال الملفات المطابقة والمحافظة على مجلد public وgames. أعد تشغيل البوت.
2) الموقع: ارفع ملفات WEBSITE إلى مشروع الموقع في GitHub/Render مكان الملفات المطابقة، ثم أعد النشر.
3) من Dashboard > سجل السيرفر: اختر روم Log، فعّل التسجيل وحدد أنواع الأحداث ثم احفظ.
4) من Dashboard > الأعضاء > Moderation: اختر روم التحذيرات واكتب ID رتبة كل مستوى. استخدم زر إضافة مستوى تحذير لإضافة مستويات أخرى ثم احفظ. الإعداد والتشغيل يحتاجان Premium+ فعّالًا.

التحذيرات في الروم المحدد فقط، في جميع السيرفرات بما فيها السيرفر الأساسي:
/warn user reason — إضافة تحذير
/warnings user — عرض آخر 10 تحذيرات فعالة والعدد الكامل
/unwarn user id — إزالة التحذير المحدد؛ دون id يزيل الأخير
تحذير @العضو السبب — إضافة تحذير
تحذير @العضو — زر لفتح نافذة السبب
تحذيرات @العضو — عرض السجل
إزالة تحذير @العضو — إزالة الأخير
كل العمليات تحتاج Manage Messages. لا يمكن تحذير نفسك أو بوت أو مالك السيرفر أو عضو بنفس رتبتك/أعلى، إلا أن مالك السيرفر يمكنه إدارة الأعضاء.
تُراجع الخطة والروم والصلاحيات مجددًا عند إرسال نافذة السبب.
كل سيرفر يحفظ سجله في member-warnings.json ضمن مخزن بياناته الخاص. الحذف يعلّم التحذير كمزال ويحفظ تاريخه. بيانات warnings.json القديمة تبقى كما هي ولا تُستورد تلقائيًا لأنها كانت خاصة بالنظام القديم.
لتطبيق رتب التحذير: أعط البوت Manage Roles وضع رتبته أعلى من رتب التحذير. يُطبق مستوى واحد حسب عدد التحذيرات، دون حد ثابت لعدد المستويات. إذا تجاوز العدد آخر مستوى، يبقى العضو على رتبة آخر مستوى. لا يوجد طرد أو حظر تلقائي.
إذا لم تظهر أوامر السلاش، استخدم مزامنة الأوامر في الداشبورد.

صلاحيات اللوج: View Audit Log + View Channel + Send Messages + Embed Links.
فعّل Server Members Intent وMessage Content Intent في إعدادات البوت (مطلوبان أصلًا في النسخة السابقة).
اللوج متاح لكل الخطط ومستقل لكل سيرفر. يسجل إجراءات سجل تدقيق ديسكورد (الرومات والرتب والصلاحيات والحظر والطرد والثريدات وغيرها)، وحذف/تعديل الرسائل، والأعضاء والفويس والألعاب وأوامر السلاش وإجراءات البوت المربوطة بالسجل.
سجل السلاش يعني استخدام الأمر وليس تأكيد نجاحه. لوبي اللعبة يسجَّل مستقلًا عن البدء عند وجود مرحلة لوبي.
لا يمكن ضمان كل حدث حرفيًا: البوت يحتاج أن يكون متصلًا ولديه الصلاحيات. محتوى الرسالة القديمة قد لا يكون متاحًا. سجل حذف المشرف مستقل ولا يُنسب تلقائيًا لرسالة بعينها. لا يسجل رسائل اللوج داخل نفسه، ولا يرسل منشن فعليًا.
وقت الازدحام الشديد يوجد حد 500 سجل معلّق لكل سيرفر مع تنبيه بعدد السجلات المتجاوزة. الطابور في الذاكرة ولا يعاد بعد إعادة تشغيل البوت.

التحقق: فحص صياغة ملفات JavaScript المعدلة واختبارات معزولة لعزل السيرفرات ومنع تكرار اللوج وإغلاق Premium/Premium+ المنتهي وتقييد الروم والصلاحيات وحفظ تحذيرين متزامنين وإزالة التحذير. لم تُجرَ تجربة مباشرة على حساب ديسكورد أو نشر على الاستضافة.
