ZOMBI WEBSITE V7.2
==================

الجديد:
- Owner يحدد Free / Premium لكل Feature ولكل لعبة.
- Gangs قابلة للتفعيل Free أو Premium.
- Dashboard لكل سيرفر يتحكم بإعدادات Gangs.
- عرض العصابات الحالية + تعديل الخزنة + تصفير انتظار المهمة + حذف العصابة.
- روم Game Panel جديد.
- زر إرسال/تحديث لوحة الألعاب من Dashboard.
- مزامنة أوامر /games /roulette /chairs /mafia /killer /ايقاف وغيرها.

رفع الموقع:
- ارفع محتويات هذا المجلد إلى GitHub repo الخاص بالموقع واستبدل الملفات القديمة.
- لا تغيّر Environment Variables في Render.
- انتظر Render حتى يصبح Live.

بعدها داخل Dashboard السيرفر:
1) اختر روم Game Panel.
2) اضغط حفظ جميع إعدادات البوت.
3) اضغط إرسال / تحديث لوحة الألعاب.
4) إذا الأوامر لم تظهر اضغط مزامنة أوامر هذا السيرفر الآن.
