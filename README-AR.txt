نظام زاجل — تحديث الداشبورد فقط

1) فك ملفات ZIP بجانب server.js وdashboard.js في مشروع الداشبورد.
2) نفّذ مرة واحدة:
   node apply-zajel-dashboard.js
3) شغّل أو أعد نشر الداشبورد كالمعتاد.
على Render يمكن تشغيل المثبت ضمن خطوة البناء بعد تثبيت المكتبات، أو قبل أمر التشغيل الحالي. مثال إذا كان تشغيل المشروع هو node server.js:
   node apply-zajel-dashboard.js && node server.js
المثبت آمن للتشغيل مجددًا؛ لا يضيف الربط مرتين. يحتفظ بنسخة احتياطية للملفات التي يعدلها.

بعد التركيب:
- حدّث صفحة الداشبورد تحديثًا كاملًا.
- افتح سيرفرك ثم زر «📨 زاجل» في قائمة الأقسام.
- فعّل النظام وحدد الروم.
- اختر الرتب التي تستطيع عرض رسائل الآخرين. المستلم يستطيع قراءة رسالته دون رتبة؛ لا تختَر رتبًا عامة إلا إذا أردت السماح لها.
- ضع روابط البنر والصورة الصغيرة للوحة الرئيسية، وروابط أخرى لبنر وصورة إشعار الرسالة المجهولة. روابط GIF المباشرة مدعومة.
- اضغط «حفظ ونشر / تحديث اللوحة» لنشر زر زاجل. زر حفظ وحده لا ينشر اللوحة.

يمكن فتح الصفحة مباشرة بإضافة /zajel بعد رابط صفحة السيرفر:
/dashboard/SERVER_ID/zajel

تُحفظ إعدادات كل سيرفر بصورة مستقلة في مصدر البيانات المشترك نفسه. لا تغيّر DATABASE_URL أو إعدادات مزامنة البوت لهذا التحديث؛ يجب أن يكون ربط البوت والداشبورد الحالي يعمل.
تغيير صور الرسائل يطبق على الإشعارات الجديدة. لتحديث صور لوحة البداية اضغط نشر / تحديث.
الداشبورد لا يعرض محتوى الرسائل السرية أو أسماء مرسليها.
