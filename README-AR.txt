ZOMBI Dashboard V12 — Tech Command Center
========================================

هذه حزمة تعديل تصميم الداشبورد فقط، بدون صور جديدة وبدون تعديل أنظمة البوت أو منطق حفظ الإعدادات.

الملفات:
- site.css: تصميم تقني داكن جديد بألوان تركواز/أزرق، تحسينات للقائمة الجانبية والبطاقات والحقول والجداول والأزرار، وحركات CSS خفيفة.
- site/dashboard.js: ملف الواجهة الحالي مرفق كما هو للمحافظة على توافق الحزمة؛ لا تستبدله إذا لم تكن بحاجة إليه.
- server.js: تحديث رقم نسخة ملفات CSS/JS إلى 12.0.0 لمنع الكاش القديم.

التركيب:
1) خذ نسخة احتياطية من site.css وserver.js.
2) استبدل site.css وserver.js من الحزمة في جذر مشروع الموقع.
3) ملف site/dashboard.js مرفق للتوافق، لكنه لم يتغير وظيفياً؛ لا حاجة لاستبداله إذا كان ملفك الحالي نفسه.
4) أعد تشغيل/نشر الموقع وافتح الداشبورد مع Ctrl+F5.

التحقق:
- تم تشغيل node --check على server.js وsite/dashboard.js.
- لم يتم تشغيل الموقع في متصفح حقيقي أو اختبار حفظ قاعدة البيانات الحية.
- لم يتم تعديل قاعدة البيانات أو إعدادات البوت أو مسارات الحفظ.
