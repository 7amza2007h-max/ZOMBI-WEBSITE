ZOMBI Dashboard — تصحيح مسارات التعديلات

سبب المشكلة السابقة: الموقع يقدّم JavaScript من الملف الموجود في جذر المشروع dashboard.js عبر مسار /site/dashboard.js، بينما الحزمة السابقة عدّلت site/dashboard.js الذي لا يقدّمه هذا المسار. لذلك لم تظهر تفاعلات التصميم الجديدة.

الملفات داخل هذه الحزمة معدّلة حسب المسارات الفعلية في المشروع:
- dashboard.js ← استبدله في جذر مشروع الموقع بجانب server.js. يحتوي على التعديلات المدمجة مع النسخة الفعلية، مع الحفاظ على أقسامها الحالية.
- site.css ← استبدله في جذر المشروع بجانب server.js.
- server.js ← استبدله في جذر المشروع بجانب dashboard.js؛ تحديث إصدار الأصول إلى 10.1.1 لإجبار المتصفح على جلب الملفات الجديدة.

قبل الاستبدال: خذ نسخة احتياطية من الملفات الثلاثة. بعد الرفع اعمل Deploy، ثم افتح الداشبورد واضغط Ctrl+F5.

الفحص المحلي: node --check dashboard.js و node --check server.js. لم يُجر اختبار متصفح/قاعدة بيانات إنتاجية؛ بعد النشر افحص التنقل والحفظ لكل قسم عمليًا.
