حماية لوحة التحكم برقم سري

1) افتح ملف .env الموجود في نفس مجلد server.js على الاستضافة.
2) أضف السطر التالي، واختر رقمًا/كلمة سر طويلة وفريدة:
   DASHBOARD_PASSWORD=ضع_الرقم_السري_هنا
3) احفظ الإعدادات وأعد تشغيل الموقع.
4) عند فتح الموقع ستظهر شاشة الرقم السري قبل لوحة التحكم أو تسجيل الدخول عبر Discord.
5) بعد إدخال الرقم الصحيح تبقى الجلسة مصرحًا لها لمدة الجلسة المعتادة، ويمكن للمستخدم بعدها تسجيل الدخول إلى Discord.
6) هذه الحماية عامة لكل الزوار، حتى لو كان البوت موجودًا في سيرفراتهم. واجهات مزامنة البوت الداخلية و/health مستثناة حتى لا تتوقف أنظمة البوت.

مهم:
- لا ترفع ملف .env إلى GitHub ولا ترسله لأحد.
- لا تضع الرقم السري في ملفات HTML أو JavaScript العامة.
- إذا لم تضف DASHBOARD_PASSWORD فلن تفتح صفحات الموقع البشرية، وستظهر رسالة إعداد الحماية.
